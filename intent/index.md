# 数据意图（形式化验证合同）

> 本层把「高频线上价格指数是否可信」转成形式化验证：界定对象、给出操作定义、建立指标、提出可证伪命题、指定验证方法。本层不涉及数据表、字段、代码与工具。

## 形式化对象

| 对象 | 记号 | 说明 |
|:--|:--|:--|
| 商品 | i | 平台上一个可唯一标识的商品 |
| 分类 | c | 官方 CPI 分类标准下的类别 |
| 日期 | t | 采集日 |
| 价格 | p_{i,t} | 商品 i 在 t 日的价格 |
| 销量 | q_{i,t} | 商品 i 在 t 日的销量 |
| 分类平均价格 | P_{c,t} | 分类 c 在 t 日的销量加权平均价格 |
| 分类指数 | I_{c,t} | 分类 c 在 t 日的指数 |
| 总体指数 | I_t | t 日的总体指数 |

外部给定：商品到分类的映射 c(i)；分类权重 w_c（按官方 CPI 口径）；基期指数 I_{c,0} = 100。

## 操作定义

- **有效价格**：p_{i,t} 非空、为正，且落在该商品历史价格的合理区间内。
- **分类平均价格**：P_{c,t} = Σ_{i∈c} p_{i,t} q_{i,t} ÷ Σ_{i∈c} q_{i,t}（销量加权）。
- **日环比**：r_{c,t} = P_{c,t} ÷ P_{c,t−1}。
- **链式分类指数**：I_{c,t} = I_{c,t−1} × r_{c,t}。
- **总体指数**：I_t = Σ_c w_c × I_{c,t}。
- **异常**：价格缺失，或偏离该商品滚动中位数超过阈值 θ。
- **断点**：某一日该分类没有可用的有效价格，无法计算 r_{c,t}。

## 指标

| 指标 | 定义 |
|:--|:--|
| 商品覆盖率 | 当日有效价格商品数 ÷ 应采商品数 |
| 有效记录率 | 有效价格记录 ÷ 采集到的价格记录 |
| 分类覆盖数 | 当日可计算出指数的分类数 ÷ 总分类数 |
| 指数连续率 | 可链式连接的日数 ÷ 应有日数 |
| 指数波动 | 日环比 r_{c,t} 的中位数、P99 |
| 异常占比 | 被判定为异常的记录 ÷ 采集到的价格记录 |

聚合维度：全局、按分类、按平台三层。

## 命题与假设

| 假设 | 内容 | 可证伪条件 |
|:--|:--|:--|
| H1 | 商品覆盖率低的日期，指数波动更大 | 覆盖率与波动无关或负相关 |
| H2 | 放宽异常阈值会提高覆盖率，但抬高指数噪声 | 放宽阈值后覆盖率与噪声不同时变化 |
| H3 | 链式指数与直接基期指数在长期上一致 | 两者长期偏离无界或方向不一 |

## 约束与不变量

- I_{c,t} > 0。
- 同一分类内，参与加权的商品销量之和为正。
- 链式连接无断点：I_{c,t} = I_{c,t−1} × r_{c,t}。
- 分类权重之和为 1。

## 验证方法

- 覆盖率、有效记录率、异常占比：描述统计与按日趋势。
- H1：覆盖率与指数波动的 Spearman 相关，报告效应量与置信区间。
- H2：不同 θ 下的覆盖率—噪声曲线，对照同一批日期。
- H3：链式指数与直接基期指数的差异序列，检验其均值与趋势。
- 与官方 CPI：按分类做对数差分的相关，仅作对标，不冒称因果。
- 因果识别：离线数据不可识别，只报相关。
