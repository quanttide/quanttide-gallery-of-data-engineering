# 数据意图

数据意图这一层，把「这个指数可不可信」从一句判断，变成可以检验的问题：先界定对象，再给操作定义，然后立指标、提命题、定验证方法。它不涉及数据表、字段、代码与工具。

## 形式化对象

案例里反复出现的名词，先固定成符号：

| 对象 | 记号 | 说明 |
|:--|:--|:--|
| 商品 | i | 平台上一个可唯一标识的商品 |
| 分类 | c | 官方 CPI 分类标准下的类别 |
| 日期 | t | 采集日 |
| 价格 | p_{i,t} | 商品 i 在 t 日的价格 |
| 销量 | q_{i,t} | 商品 i 在 t 日的销量 |
| 分类平均价格 | P_{c,t} | 分类 c 在 t 日的销量加权平均价格 |
| 分类指数 | I_{c,t} | 分类 c 在 t 日的指数 |
| 总体指数 | I_t | t 日的总体指数 |

外部给定三项：商品到分类的映射 c(i)、分类权重 w_c（按官方 CPI 口径）、基期指数 I_{c,0} = 100。

## 操作定义

每个概念都给出可执行的定义，而不是靠语感。有效价格指 p_{i,t} 非空、为正，且落在该商品历史价格的合理区间内。分类平均价格 P_{c,t} 按销量加权，即 Σ_{i∈c} p_{i,t} q_{i,t} ÷ Σ_{i∈c} q_{i,t}。日环比 r_{c,t} 是当期与上一期平均价格之比；链式分类指数 I_{c,t} 等于上一期指数乘以日环比；总体指数 I_t 是各分类指数按权重 w_c 的加权和。异常指价格缺失，或偏离该商品滚动中位数超过阈值 θ；断点指某一日该分类没有可用的有效价格，无法计算 r_{c,t}。

## 指标

指标分两类：一类看数据够不够用，一类看指数稳不稳。商品覆盖率是当日有效价格商品数占应采商品数的比例；有效记录率是有效价格记录占采集记录的比例；分类覆盖数是能算出指数的分类占全部类别的比例；指数连续率是可链式连接的日数占应有日数的比例；指数波动取日环比 r_{c,t} 的中位数与 P99；异常占比是被判为异常的记录占采集记录的比例。

聚合维度：全局、按分类、按平台三层。

## 命题与假设

命题先立可证伪的条件，再谈验证。三条假设都写成「什么情况下它被推翻」：

| 假设 | 内容 | 可证伪条件 |
|:--|:--|:--|
| H1 | 商品覆盖率低的日期，指数波动更大 | 覆盖率与波动无关或负相关 |
| H2 | 放宽异常阈值会提高覆盖率，但抬高指数噪声 | 放宽阈值后覆盖率与噪声不同时变化 |
| H3 | 链式指数与直接基期指数在长期上一致 | 两者长期偏离无界或方向不一 |

## 约束与不变量

不论数据怎么变，这四条必须成立：指数恒为正；同一分类内参与加权的商品销量之和为正；链式连接无断点，即 I_{c,t} = I_{c,t−1} × r_{c,t}；分类权重之和为 1。

## 验证方法

每条命题对应一种检验：

- 覆盖率、有效记录率、异常占比：描述统计与按日趋势。
- H1：覆盖率与指数波动的 Spearman 相关，报告效应量与置信区间。
- H2：不同 θ 下的覆盖率—噪声曲线，对照同一批日期。
- H3：链式指数与直接基期指数的差异序列，检验其均值与趋势。
- 与官方 CPI：按分类做对数差分的相关，仅作对标，不冒称因果。

因果识别：离线数据不可识别，只报相关。
